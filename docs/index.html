Elite Dangerous Anti-Aliasing

Temporal Anti-Aliasing (TAA) for Elite Dangerous Odyssey, as a ReShade add-on.

Download Latest Release View Source

TAA

Sub-pixel jitter and motion vectors rebuilt from the game's own camera and depth: stable edges, no ghosting when you turn, fly, drive or walk.

Crisp Cockpit HUD

The TAA runs inside the game's frame, before the HUD, bloom and tonemapping. Your HUD stays sharp, maps and high-res screenshots are left untouched.

One-Click Setup

The installer finds the game (Steam, Epic, Frontier) and sets up ReShade if needed. Works alongside EDHM.

Quick Start Guide

1

Download & Install

Run EDAA-Setup-x.y.z.exe from the latest release. It installs ReShade 6.8 with full add-on support if it is missing.

2

Turn the Game's AA Off

In Options > Graphics, set anti-aliasing to Off: EDAA replaces it.

3

Fly

TAA is on by default. Ctrl+Shift+T toggles it, Home opens the ReShade overlay (tab "EDAA") for status and settings.

Good to know

  • Requires Elite Dangerous Odyssey (DirectX 11) and ReShade 6.8+ with full add-on support.
  • Settings are saved in ReShade.ini; "Reset to defaults" restores them.
  • ReShade's add-on build is meant for single-player games. Elite Dangerous has no anti-cheat blocking it, but use it at your own discretion.
  • Uninstall from Windows Settings > Apps > EDAA (ReShade stays).
